How it works

01 · SCRAPE

Read the product page

Title, price, description and photos come straight from the store. No manual input.

02 · DIRECT

Kimi directs three ads

Kimi K3.1 Pro on Cerebras studies the photos, invents three concepts and writes a storyboard for each: which scenes, in what order, at what pace.

03 · RENDER

Stage and export

A kit of eleven designed scene types stages each storyboard in HyperFrames, adds a generated soundtrack, and renders MP4s.

What these numbers do and don't include
  • Write time is Kimi's own generation time as reported by Cerebras. During the hackathon each request also waited in a queue first; that wait is shown separately on each video.
  • Copy is written by the model from the product page and has not been fact-checked.
  • Product names and photos belong to their brands. These are demo videos, not ads run by those brands.

Run it yourself

Needs Node 24.16+, FFmpeg and a Cerebras API key with Kimi K3.1 Pro access.

git clone https://github.com/backspacevenkat/kimi-product-shorts
cd kimi-product-shorts && npm ci
export CEREBRAS_API_KEY=...
node src/make.mjs https://store.example.com/products/some-product

# brief written by an OpenClaw agent turn
BRIEF_VIA=openclaw node src/make.mjs https://store.example.com/products/some-product
