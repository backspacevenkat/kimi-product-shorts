    How it works

    01 · PASTE

    Paste your product link

    The title, price, description and photos come straight from your store. Nothing to upload, nothing to type.

    02 · WRITE

    Three different ad ideas

    An OpenClaw agent studies your product and writes three concepts, each with its own storyboard, look and pace. Cerebras makes that take seconds instead of minutes.

    03 · POST

    Videos for every platform

    Each storyboard becomes a 15-second video with its own soundtrack. Download it sized for Shorts, Reels, TikTok, feed, square or landscape.

    The fine print
    • The agent's model is Kimi K3.1 Pro, served by Cerebras and run through OpenClaw. Videos are staged and rendered with HyperFrames.
    • "Under a minute" is the work itself: reading the page, writing three ads and rendering three videos. When Cerebras is busy, a request waits in its queue first; that wait is shown separately on each video.
    • The wording is AI-written from the product page and has not been fact-checked.
    • Product names and photos belong to their brands. These are demo videos, not ads run by those brands.

    Run it yourself

    Needs Node 24.16+, FFmpeg and a Cerebras API key with Kimi K3.1 Pro access.

    git clone https://github.com/backspacevenkat/kimi-product-shorts
cd kimi-product-shorts && npm ci
export CEREBRAS_API_KEY=...
node src/make.mjs https://store.example.com/products/some-product

# brief written by an OpenClaw agent turn
BRIEF_VIA=openclaw node src/make.mjs https://store.example.com/products/some-product
